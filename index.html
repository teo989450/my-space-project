Екологія та сталий розвиток

Екологія вивчає взаємодію живих організмів між собою та з навколишнім середовищем. Цей річний проєкт спрямований на дослідження стану довкілля та пошук шляхів раціонального використання природних ресурсів. Головна мета роботи полягає у створенні практичного цифрового рішення для підвищення екологічної свідомості.

Гра

Інтерактивний симулятор для навчання правилам сортування відходів та ощадливого споживання ресурсів у повсякденному житті.

Бот

Автоматизований помічник у месенджері для швидкого пошуку пунктів прийому вторсировини та отримання щоденних екопорад.

Сайт

Інформаційна вебплатформа з матеріалами дослідження, інтерактивними пам'ятками та корисними інструментами для збереження природи.

Застосунок

Зручний мобільний трекер для обліку особистих екологічних звичок, фіксації прогресу та формування відповідального споживання.
